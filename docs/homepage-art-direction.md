# 敦煌有信：真实坐佛与城市叙事

设计主题：一眼，千年。保留开场「特写 → 拉远 → 全貌」的深色砂金风格，以一段连续的数字旅程连接展品，不再进入第二套展览。

## 页面与镜头

观看顺序：序章 → 敦煌 → 伦敦 → 巴黎 → 数字化与来源。

序章保持原来的滚动长度（桌面 320svh、手机 300svh）、三幕文字、光影与经文叠层。相机进度仍使用 `1 - (1 - p)^2.1`；第一、二、三幕的逻辑边界为 25%、64%。文字淡入由原来的连续 CSS 曲线控制。反向滚动可返回前幕，底部「见微／观像／有信」可跳转。减少动画时直接呈现最后一幕。

- 第一幕：「一眼，千年。」／「循着微光，与千年相逢。」
- 第二幕：「光落在木上，时间有了形状。」／「在一寸纹理里，与遥远的岁月相遇。」
- 第三幕：「敦煌有信。」／「一卷经文，一页乐谱，一尊坐佛。从敦煌出发，在伦敦与巴黎走近遗珍。」
- 按钮：「从敦煌出发」直接滚动到敦煌章节；「走近伦敦馆藏」定位伦敦。

敦煌介绍共同文化源头和阅读路线；伦敦依次展示《金刚经》、木雕坐佛；巴黎展示琵琶谱。三件展品各有唯一详情区域和自己的固定问答。路线明确是观看顺序，不表示所有文物都依次经过伦敦、巴黎。

顶部固定导航为「序章／敦煌／伦敦／巴黎／来源」。手机保留全部入口，锚点预留导航高度。原先三列导览、旧版首屏、末尾整套展品选择区已移除。

## 暗中浮现与队徽（2026-10-07）

首屏让标题先成为视觉中心，照片与模型共用 `.dh-artwork` 视觉层，不模糊文字，不修改文物纹理。显现曲线以 smoothstep 插值连接 0%→4%、12%→12%、25%→70%、36%→100%；独立暗色遮罩为 `0.68 × (1 - reveal)`。手机在此基础上保留 `1 - 0.4 × p` 的末幕压暗。相机缓动、滚动时长、三幕边界保持原样；反向滚动没有额外时间动画。模型首次实际绘制后才报告 ready、替换照片，不在下载完成时提前隐藏照片。失败回退使用相同进度与视觉层。

队徽来自团队提供的队旗元素：手写 iD 与飞天飘带，提炼为原创透明底 SVG，未使用外部字体、校徽或图像生成服务。导航主标识为 `public/assets/team-emblem.svg`；浅色背景用 `team-emblem-purple.svg`；`team-emblem-small.svg` 和新版 favicon 用于小尺寸显示。桌面 44 px、手机 32 px。队旗原件备份在 `assets/brand/team-flag-original.jpg`，与 `dist/assets/队旗final.jpg` 哈希相同，原文件保留。

显现曲线测试运行 `npm test`，覆盖关键值、范围、单调性、连续性与反向求值。浏览器对照画面保存在忽略的 `.qa/reveal-*`；改版对照与队徽预览交付为 `assets/brand/revision-preview.jpg`。此次没有新模型生成、积分消耗、GitHub 上传或部署。

## 坐佛图像与 3D 模型

当前使用团队提供的真实馆藏照片 `1613966443.jpg`，不是艺术示意图。五张原图已复制到 `public/assets/buddha-reference/`，展示照片为 `public/assets/buddha-real.jpg`；原先 `dist/assets/real image/` 的文件保留。

已通过 Tripo 生成两版多视图 GLB，采用第二版。输入来自同一灰底摄影组：正面 `1144299001.jpg`、背面 `1144300001.jpg`；只本地裁掉底部标尺、保留原始像素，不采用改变纹理的 AI 抠图试稿。网页模型为 97,182 三角面、2K 内嵌贴图、8.90 MB；高分辨率原版保存在非发布目录。生成与积分记录详见 [模型记录](buddha-model.md)。

默认加载 `public/assets/buddha.glb`，无需环境变量。可通过 `.env.local` 的 `VITE_BUDDHA_MODEL_URL` 覆盖地址，或设置 `off` 完全使用真实照片。更换模型后需重新检查朝向及运镜。相机补偿实际模型厚度，小屏最后一幕额外留出莲座侧缘空间；开场特写、滚动时长与文字出现时机保持。

说明统一为「依据馆藏照片生成的数字重建」，不是馆方扫描或考古测绘。照片署名与模型制作署名分别保存在 `src/data.ts`；当前原图署名为 © The Trustees of the British Museum，由团队提供。逐张图片的授权证明尚未提供，公开宣传前仍须核实原图使用条件，非商业用途不自动等于获得授权。

首页不允许手动旋转；同一滚动进度驱动相机特写、拉远、全貌。展品区提供旋转、缩放、复位和原图切换。两个查看器共享已解析的模型资源，展品查看器接近视口时才加载。无 WebGL、加载失败或上下文丢失时回退到真实照片。

## 实现位置

- `src/App.tsx`：连续页面、城市叙事、独立问答、来源页尾、四页阅读弹窗。
- `src/Homepage.tsx` 与 `src/homepage.css`：序章进度和原有三幕动画。
- `src/BuddhaModel.tsx`：共享 GLB 缓存、Three.js 相机与模型控制。
- `src/BuddhaViewer.tsx`：接近视口加载、原图切换和失败回退。
- `src/journey.css`：城市章节、展品布局及手机适配。
- `src/data.ts`：展品事实、来源、照片与模型字段、固定问答。

历史锚点继续有效：`#journey` 为敦煌、`#collection` 为伦敦、`#dialogue` 为《金刚经》问答，以及三个 `#exhibit-*`。

## 本轮验证与边界

- 修改前后记录桌面与手机 0%、12%、25%、43%、64%、100% 的序章画面；照片版沿用原进度和构图规则。浏览器取整可能令 64% 采样略小于边界，不代表文字曲线发生改变。
- 用测试页延迟释放模型请求，验证等待和就绪状态在 0% 时均为 4% 模型层透明度、0.6528 遮罩；中途滚动至 43% 后载入继续当前镜头。未使用真实网络限速，不替代现场网络性能测试。
- 已在浏览器检查连续路线、每件展品唯一详情区域、原有卷轴热点、四页阅读与放大、各展品问答、模型／原图切换。
- 实际坐佛 GLB 已验证共享一次加载、拖动旋转、缩放、复位、原图切换、缺失模型、无 WebGL 及模拟上下文丢失回退。先前几何体测试不替代此次实际模型验收，也不进入发布包。
- 减少动画的 JavaScript 分支已用测试页模拟；原生媒体查询样式保留。真实设备的系统减少动画设置仍建议团队再验证。
- TypeScript 与生产构建通过。Three.js 核心懒加载文件仍有打包体积提示；运行时不请求海外图像或建模服务。
- 已对照实际 GLB 的桌面与手机尺寸镜头，检查朝向、正背面细节、面数、贴图及体积。320/390 像素无横向溢出；浏览器视口模拟不能代替真实低端手机 GPU 性能验证，现场仍需复核。未提交 GitHub、未部署。
