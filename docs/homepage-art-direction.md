# 敦煌有信：首页艺术设计与文案

设计主题：一眼，千年。

参考用户提供的产品网页录屏，采用「特写 → 拉远 → 全貌 → 阅读」的观看顺序。首页沿用第一版的深色氛围、砂金标题、左侧入口和右侧坐佛，将滚动开场与正式入口统一为一段视觉叙事。

## 页面与镜头

| 位置 | 画面与版式 | 显示文案 |
| --- | --- | --- |
| 开场 0–20% | 佛像极近特写铺满画面；中心大字；顶部为安静的品牌与导航 | 一眼，千年。／走近一点，时间自有回声。 |
| 20–60% | 镜头逐步拉远，文字移至左侧；主体留在中右位置 | 光落在木上，时间有了形状。／在一寸纹理里，与遥远的岁月相遇。 |
| 60–100% | 完整坐佛位于右侧，经文轻淡显露；落到第一版的左右构图 | 敦煌有信。／一卷经文，一页乐谱，一尊坐佛。散落远方的敦煌，在此相逢。 |
| 继续向下 | 转为纸本色展品导览，三列错落排列；手机依次纵向阅读 | 三件遗珍，三种回响。 |

页面随滚动推进，向上滚动可返回前幕。下方的「见微／观像／有信」可直接定位到三幕；顶部「进入展览」始终可用。用户设置减少动画时，直接呈现最后一幕。动画进度依附页面滚动，不设置自动播放的倒计时。

## 视觉规则

- 墨黑 `#080B0B`：开场背景与页尾。
- 砂金 `#D5B98A`：标题重点、章节与入口。
- 绢白 `#EEE6D6`：深色画面上的正文。
- 纸本色 `#EEE7D9`：展品导览背景。
- 少量赭色：品牌「敦」字与标题句点。
- 标题用宋体／衬线字体，正文用清晰的无衬线字体；中文是主要信息，英文仅作小型辅助标识。
- 桌面左右留白约 7.5%，首幕中心标题约 72–132px，最终品牌标题约 66–112px；手机缩至约 40–64px。
- 主体、光影和文字构成层次。正文不覆盖佛像的面部与双手，按钮在暗色留白区域。
- 展品导览用纵向分隔、图像和字号组织，不使用大圆角卡片与密集装饰。

## AI 视频画面交付要求

视觉目标是一段连续运镜，而非拼接多个无关画面。建议 6–8 秒、16:9、无声；镜头从木雕面部或衣褶极近景开始，经过轻微侧向运镜与明显拉远，停在完整坐佛的全景。

首帧：细节足够大，允许画面呈抽象的木纹与金漆质感，中心文字仍应清楚。

中段：主体逐渐移至中右侧，左侧 40% 保持较暗，供第二幕文字出现。

尾帧：佛像占右半区，完整保留头部与莲座，左侧约 45% 是暗色留白。相机停稳，便于首页标题和按钮出现。

暖侧光负责表现木质与雕刻层次；主体全程静止。AI 成片不包含网页文字、按钮、导航或经文重绘。经文扫描可另行叠加。参考视频中的真实三维视角变化取决于模型成片质量，当前静态素材预演不等同于最终效果。
